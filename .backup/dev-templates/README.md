# Development Templates

This directory contains template files for reference and development purposes only.

## Purpose

- **Local Reference**: Keep templates accessible for development and reference
- **No Production Impact**: Excluded from builds, linting, and version control
- **Clean Main App**: Keeps the main application focused on production code

## Structure

- `course-templates/` - Course-related page templates
- `dashboard-templates/` - Dashboard and admin templates
- `page-templates/` - General page templates
- `scale-up-templates/` - Scaling and growth templates
- `test-supabase-auth.js` - Manual Supabase authentication testing script

## Usage

These templates are available locally for:

- Copying patterns and components
- Reference for styling and layout
- Development inspiration
- Testing new features

## Testing Script

The `test-supabase-auth.js` script is a manual testing tool for:

- Testing Supabase authentication flows
- Testing file upload functionality
- Testing signed URL generation
- **⚠️ Contains hardcoded credentials - use only for local testing**

## Note

These files are:

- ✅ Available locally for reference
- ❌ Not included in production builds
- ❌ Not linted (no warnings/errors)
- ❌ Not committed to version control
